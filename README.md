## ✨ 核心功能与技术亮点

1. **集卡式卡面与 3D 陀螺仪全息折射 (3D Tilt & Holographic Foil)**
   - 鼠标在卡片上方移动时，卡片跟随光标实时计算角度，产生平滑的 3D 视角微倾斜。
   - 动态全息彩虹光栅（Rainbow Prismatic Sheen）与高光反射算法，呈现真实实体镭射球星卡质感。
   - 卡面包含 OVR 盾牌、位置标签、国旗、队徽、5颗闪烁金星（★★★★★）与 6 大 FUT 核心属性（进攻、防守、投射、组织、篮板、体能）。

2. **3D 翻转卡背 · 深度指标与能力雷达**
   - 点击卡片触发平滑 3D 翻转动画。
   - **六维能力蜘蛛网雷达图**：自主封装高精度 SVG 雷达图，实时渲染球员六大维度。
   - **细分能力数值面板（0-99）**：投射能力、禁区终结、组织传球、防守封锁。
   - **赛季真实高阶数据看板**：场均得分、篮板、助攻、命中率（FG%/3P%）、真实命中率（TS%）。
   - **特质金徽章与球探档案**：详细记录球员战术优劣势与乌度卡战术定位。

3. **半场战术球场阵型板 (Half-Court Tactical Board)**
   - 真实还原休斯顿丰田中心半场硬木地板与火箭红油漆区。
   - 五虎落位于真实战术坐标点，带有动态**战术羁绊连线**（如 1-5 号位挡拆轴心、锋线无限换防扫荡）。
   - 点击球场上的任意球员头像即可直接联动卡片。

4. **双人球星深度数据对比 (Head-to-Head Compare)**
   - 任意挑选两位球星进行双层半透明雷达图覆盖对比与全属性对抗 PK。

5. **抽卡开包入场动画 (Pack Opening Ceremony)**
   - 沉浸式拆封火箭专属限量卡包，金光爆炸与礼花（Confetti）散落。

6. **Web Audio API 纯代码实时音效**
   - 翻牌破风声、悬停微共鸣、拆包庆祝和弦均由 Web Audio API 合成，零外部音频资源依赖，支持一键静音。
